# DOXA Methodology
Status: Controlled reference / evolving

## Core model

### Readability — Kann KI uns verstehen?
Focus: identity, offer, target group, differentiation, technical and semantic clarity, structured data, website and content.

### Visibility — Kann KI uns finden?
Focus: whether sufficiently relevant signals about the brand are present across the information ecosystem.

### Credibility — Kann KI uns glauben?
Focus: independent corroboration, authority, trusted third-party signals, reviews, expert or media validation and consistency.

## Service logic
**Audit → Strategie → Umsetzung → Monitoring**

## Learning loop
**Messen → Verstehen → Verändern → erneut messen.**

## Important boundary
This is DOXA's strategic working model. Do not describe the proprietary framework itself as scientifically validated unless that validation exists.
